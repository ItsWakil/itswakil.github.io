Based on a conversation I had this morning. 

## The equation

```text
DO = W ∨ O        (Want OR Obligated)

¬W ∧ ¬O  →  ¬DO   (∀ J)
```

## The truth table

```text
 WANT │ OBLIGATED │ JUSTIFIED │  DO IT?
──────┼───────────┼───────────┼─────────
  ✓   │     –     │     –     │   YES
  ✗   │     ✓     │     –     │   YES
  ✗   │     ✗     │     ✓     │   NO  ← J ignored
  ✗   │     ✗     │     ✗     │   NO
```

## The flowchart

```text
        ┌───────────────┐
        │ Do I want to? │
        └───────┬───────┘
          yes ┌─┴─┐ no
              │   │
              ▼   ▼
           ┌────┐ ┌──────────────────┐
           │ DO │ │ Am I obligated?  │
           └────┘ └────────┬─────────┘
                     yes ┌─┴─┐ no
                         │   │
                         ▼   ▼
                      ┌────┐ ┌────────┐
                      │ DO │ │ DON'T  │
                      └────┘ └────────┘
                                 ▲
              justifications ────╳   (blocked)
```

> **Want or Must. Nothing else moves me.**
